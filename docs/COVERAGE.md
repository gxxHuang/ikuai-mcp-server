所有端点经 **IK-Q3000 / 固件 4.0.313 x64 (arm, 免费版)** 逐条实机调用核对。

## 安全管控 (39)

## 高级服务 (30)

## 日志中心 (11)

## 已知限制(免费版)

实测 4.0.313 免费版未编译以下模块,调用返回 `code=1003`(属预期,非 bug):

| 模块 | 说明 |
|------|------|
| `tcpdump` add/start/detail | 抓包规则创建不可用;列表与网口查询可用 |
| `smbd` / `ftp_server` / `http_server` | 本地文件服务未编译 |
| `pppoe_proxy_online` | 代拨在线列表(企业版功能) |
| `disk_mgmt` / `docker_*` / `appmarket_*` | 磁盘管理、容器、应用市场 |

对应工具在 docstring 中已标注限制,失败时返回结构化说明而非静默异常。
